# Surface spectral analysis — synthetic model slab

> **SYNTHETIC MODEL. NOT DFT DATA. NOT ARPES.**
> The Hamiltonian and overlap in this example are generated by a few lines of
> Fortran (`gen_model.f90`) with hand-picked parameters. They do not describe
> any real material. The maps are broadened projection weights, not simulated
> photoemission intensities.

The repository contains no real OpenMX slab, so this example exercises the
full surface pipeline on a deterministic, non-orthogonal LCAO-like
tight-binding slab that has well-defined surface states:

```
gen_model  ->  atomselect  ->  spectral  ->  specmap (x2)  ->  gnuplot
                              spectral (&KGRID) -> specmap (energies) -> gnuplot   (constant-energy maps)
```

## Running

From the repository root (or from anywhere — the script `cd`s into its own
directory and builds with `fpm` from the repository root):

```bash
bash examples/surface_spectral/run_example.sh
NO_PLOT=1 bash examples/surface_spectral/run_example.sh   # skip the gnuplot step
```

The gnuplot step is also skipped (with a message) when `gnuplot` is not
installed. Every run starts by deleting all generated files, including
`regions.nml`, which is regenerated by `atomselect`; the committed
`regions.nml` is the reference result of those commands.

## The model

Generated by `fpm run --example surface_model` (program `gen_model.f90`),
which writes `model_H.hsio`, `model_S.hsio` and `model.nml` into the current
directory.

| item | value |
|---|---|
| lattice | a1 = (3,0,0), a2 = (0,3,0), a3 = (0,0,40) Å (vacuum along z) |
| layers | NL = 8, one atom per layer at (0, 0, z), z = 13, 15, …, 27 Å (spacing 2.0 Å) |
| species | odd layers `A` (2 orbitals: s, pz), even layers `B` (1 orbital: s) → NOrbs = 12 |
| atom order | atom 1 = bottom layer (A), atom 8 = top layer (B) |
| cells (IndexList) | (0,0,0), (±1,0,0), (0,±1,0); Degenerecency = 1 |
| on-site H (eV) | A_s = −1.20, A_pz = +4.00, B_s = +1.80 |
| surface potential | top B_s shifted by −2.00 (→ −0.20); bottom A_s shifted by +1.80 (→ +0.60) |
| interlayer H (R = 0, adjacent layers) | s–s = −0.60; A_pz–B_s = +0.50 if B is above A, −0.50 if below |
| in-plane NN H (R = ±a1, ±a2, same orbital) | s = −0.15, pz = +0.10 |
| S | identity on site; interlayer s–s 0.10, pz–s ±0.05; in-plane s 0.08, pz 0.05 |

Hermiticity holds by construction: the R = 0 block is symmetric and
`Data(:,:,-R) = Data(:,:,R)^T` for the (diagonal, real) in-plane blocks.
Data convention: `Data(:,:,iR) = <i in cell 0|H|j in cell IndexList(:,iR)>`,
`H(k) = Σ_R Data(:,:,R) exp(+i2πk·R)`.

Physics of the model: the alternating A_s/B_s on-site energies open a bulk gap
along z; the surface potentials pull one state from each end into that gap,
the top one (on atom 8) and the bottom one (on atom 1) at different energies.
**E_F = 0 by construction**: the parameters are chosen so that E = 0 lies in
the bulk gap and crosses both surface bands; no shift is applied by any
program, hence `energy_reference = 'fermi'` in `spectral.nml`.

Note how the non-orthogonal overlap affects the dispersion: the lowest bulk
manifold (near −1.5 eV) is almost flat because, for the generalised problem,
the in-plane s hopping (−0.15 eV) is largely cancelled by E·S_inplane
(≈ −1.5 × 0.08 eV).

## Pipeline (exactly what `run_example.sh` runs, inside this directory)

`$GEN`, `$ATOMSELECT`, `$SPECTRAL`, `$SPECMAP` are the fpm build paths found
with `fpm run <target> --runner echo`.

```bash
$GEN                                                     # model_H.hsio model_S.hsio model.nml
$ATOMSELECT inspect  model.nml
$ATOMSELECT layers   model.nml --normal 0 0 1
$ATOMSELECT surface  model.nml --regions regions.nml --normal 0 0 1 --top 1 --bottom 1
$ATOMSELECT select   model.nml --regions regions.nml --name interior --atoms "2-7"
$ATOMSELECT validate model.nml regions.nml               # reports "partition : yes"
$SPECTRAL spectral.nml                                   # Mulliken, X-G-M, write_text
$SPECMAP  specmap.nml                                    # Lorentzian, eta = 0.05 eV
$SPECMAP  specmap_gauss.nml                              # Gaussian, sigma = 0.10 eV
$SPECTRAL spectral_kgrid.nml                             # 81 x 81 k-grid over the surface BZ
$SPECMAP  specmap_ce.nml                                 # constant-energy maps at E = -1, 0, +1 eV
gnuplot plot_spectral.gp                                 # skipped if NO_PLOT=1 / no gnuplot
```

`specmap_gauss.nml` re-broadens the same `model.spectral.bin`: changing the
kernel, width or energy window never requires re-running `spectral`
(specmap reads no HSIO and performs no diagonalisation).

## Outputs (all git-ignored except `regions.nml`)

| file | produced by |
|---|---|
| `model_H.hsio`, `model_S.hsio`, `model.nml` | gen_model |
| `regions.nml` (`top` = [8], `bottom` = [1], `interior` = [2–7]) | atomselect |
| `model.spectral.bin`, `model.spectral.txt` | spectral |
| `model.{total,top,bottom,interior,top_minus_bottom,top_plus_bottom}.map.dat`, `model.kticks.gp` | specmap (Lorentzian) |
| `model_gauss.{total,top,bottom,top_minus_bottom}.map.dat`, `model_gauss.kticks.gp` | specmap (Gaussian) |
| `model_kgrid.spectral.bin` | spectral (`spectral_kgrid.nml`, `&KGRID`) |
| `model_ce.{total,top,top_minus_bottom}.E{-1.000,+0.000,+1.000}.cemap.dat`, `model_ce.cegrid.gp` | specmap (`specmap_ce.nml`) |
| `model_total`, `model_top`, `model_top_minus_bottom`, `model_top_vs_bottom`, `model_ce_top_EF`, `model_ce_top_minus_bottom_EF` (`.png` + `.pdf`) | plot_spectral.gp |

`plot_spectral.gp` is a thin wrapper around `tools/gnuplot/map_positive.gp`,
`map_difference.gp` (divergent palette centred at 0; red = top, blue = bottom)
and `map_compare.gp` (top | bottom, common colour scale). Run it from this
directory (`gnuplot plot_spectral.gp`) and open the PNG/PDF files with any
image viewer.

## Constant-energy maps

`spectral_kgrid.nml` replaces `&KPATH` by an 81 × 81 `&KGRID` covering the
whole surface Brillouin zone (`origin = -0.5,-0.5,0`, `span1 = b1`,
`span2 = b2`, Γ at the centre); `specmap_ce.nml` then cuts it at
E = −1, 0 and +1 eV. At E = E_F = 0 the `top − bottom` map
(`model_ce_top_minus_bottom_EF.png`) shows the two Fermi contours of the
model: a small pocket of the **bottom** surface state around Γ (blue) and the
**top** surface state around the M corners (red), consistent with the path
results above (E_F crosses the bottom band on both X–Γ and Γ–M, the top band
only on Γ–M).

## Band, weight, spectral function, map, ARPES

- **Band** ε_n(k): eigenvalue of H(k)c = εS(k)c along the path.
- **Projection weight** w_n^P(k): fraction of state n on region P (Mulliken
  here; sums to 1 over a partition; can be slightly negative in a
  non-orthogonal basis).
- **Projected spectral function** A_P(k,E) = Σ_n w_n^P(k) K(E − ε_n(k)):
  weights broadened by an artificial kernel K (Lorentzian or Gaussian of
  chosen width) — not a many-body spectral function.
- **Intensity map**: A_P (or a ± combination of regions, optionally times a
  Fermi–Dirac occupation) on an (k, E) grid, as written by specmap.
- **ARPES**: a measured photoemission intensity, which also involves matrix
  elements, photon energy and polarisation, final states, k_z broadening,
  resolution and many-body effects. None of these are modelled here.
